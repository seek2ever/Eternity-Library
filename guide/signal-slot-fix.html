🔧 后台线程触发方案修复

问题诊断：refresh_cover_view 中调用 QTimer.singleShot(0, self._book_worker.fetch_all_books)，但 QTimer.singleShot 会在调用方所在线程（主线程）执行回调，fetch_all_books 实际上跑在主线程，没有利用后台线程。

✓ 修复方案：在 BookQueryWorker 中新增一个触发信号 trigger_fetch，连接到 fetch_all_books 槽函数。Qt 检测到跨线程时自动使用 QueuedConnection，确保方法在后台线程执行。

修改文件 1：database.py

第 320 行附近，在 Signal 声明区域新增一个 trigger_fetch 信号

修改前（第 320-321 行）：

class BookQueryWorker(QObject): books_ready = Signal(list) query_error = Signal(str)

修改后：

class BookQueryWorker(QObject): books_ready = Signal(list) query_error = Signal(str) trigger_fetch = Signal() # 触发 fetch_all_books 在后台线程执行

同时，给 fetch_all_books 加上 @Slot() 装饰器（第 344 行）：

修改前：

def fetch_all_books(self): """查询全部书籍（在工作线程中执行）""" self._execute_query("SELECT * FROM books_information")

修改后：

@Slot() def fetch_all_books(self): """查询全部书籍（在工作线程中执行）""" self._execute_query("SELECT * FROM books_information")

注意：需要从 PySide6.QtCore 导入 Slot。检查文件顶部 import，如果已有 Signal 导入通常就够了，但 @Slot() 需要额外导入。如没有，在 from PySide6.QtCore import ... 中添加 Slot。

修改文件 2：el_gui.py

修改 A：_setup_book_worker 方法（第 80-96 行）

在 connect 区域新增 trigger_fetch 的连接：

修改前（第 92-94 行）：

# 连接信号和槽 self._book_worker.books_ready.connect(self._on_books_loaded) self._book_worker.query_error.connect(self._on_query_error)

修改后：

# 连接信号和槽 self._book_worker.books_ready.connect(self._on_books_loaded) self._book_worker.query_error.connect(self._on_query_error) # trigger_fetch → fetch_all_books：跨线程自动 QueuedConnection self._book_worker.trigger_fetch.connect(self._book_worker.fetch_all_books)

修改 B：refresh_cover_view 方法（第 403-417 行）

把 QTimer.singleShot 改成 emit 信号：

修改前（第 411-417 行）：

# 缓存过期或不存在 → 触发后台线程查询 # QMetaObject.invokeMethod( # self._book_worker, # b"fetch_all_books", # Qt.QueuedConnection # 确保在工作线程的事件循环中执行 # ) QTimer.singleShot(0, self._book_worker.fetch_all_books)

修改后：

# 缓存过期或不存在 → 触发后台线程查询 self._book_worker.trigger_fetch.emit()

注意：修改后 QTimer 在 el_gui.py 中可能不再使用。如果 IDE 提示 QTimer 导入未使用，可以删除导入。不过保留也不影响运行，看你自己习惯。

database.py 第 344 行（fetch_all_books 前） 加 @Slot() 装饰器

改动前后的执行流程对比

修改前（QTimer.singleShot）：

refresh_cover_view()  [主线程]
  └─ QTimer.singleShot(0, ...)  [定时器在主线程事件循环触发]
      └─ fetch_all_books()  ❌ 仍然在主线程执行！

修改后（信号槽）：

refresh_cover_view()  [主线程]
  └─ trigger_fetch.emit()
      └─ Qt: 检测到跨线程 → 自动 QueuedConnection
          └─ fetch_all_books()  ✅ 在后台线程的事件循环执行
              └─ _execute_query()  [后台线程]
                  ├─ 成功 → books_ready.emit(list)
                  │         └─ MainThread 收到结果，_on_books_loaded 更新 UI
                  └─ 失败 → query_error.emit(str)
                            └─ MainThread 收到错误，_on_query_error 处理
